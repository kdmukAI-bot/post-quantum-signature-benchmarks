# Environment: RP2350 (Waveshare RP2350 Touch LCD 2)

| Item | Value |
|---|---|
| Board | Waveshare RP2350 Touch LCD 2: RP2350 revision A2, package QFN60 (RP2350A), 16 MiB flash (picotool) |
| Cores and clock | two Arm Cortex-M33 at 150 MHz (the SDK default; each log's `#env` line); the Hazard3 RISC-V cores are not used |
| Memory | 520 KB SRAM; code runs in place from flash through the 16 KB XIP cache unless placed in SRAM; flash clock divider 3 (50 MHz), as read at run time |
| Console | USB CDC (`pico_stdio_usb`); no reset between job sets |
| Toolchain image | `pqb-rp2350:sdk2.3.1-gcc14.2` from `harness/pico/docker/Dockerfile`: debian:12-slim by digest, Arm GNU Toolchain 14.2.rel1 (GCC 14.2.1 20241119), Pico SDK 2.3.1 (079c6f39; TinyUSB 86ad6e56), picotool 2.3.1 (20419364), raspberrypi/FreeRTOS-Kernel 4f7299d6 (V11.1.0+) |
| RTOS | FreeRTOS SMP on both cores (RP2350_ARM_NTZ port), tick 100 Hz, heap_4 of 400 KiB (394,280 bytes free when a job set starts), stack overflow check method 2, per-task PSPLIM |
| Safeguards | the SDK's Release defaults (NDEBUG), FreeRTOS's stack overflow check, the port's per-task stack limit register; no compiler stack protector; a hardware watchdog fed from the tick interrupt with a recording HardFault handler (`harness/pico/pqb_rp_fault.c`), the counterpart of ESP-IDF's interrupt watchdog and panic handler |
| Sources | the three submodules at their pinned commits, unmodified; the same vector blobs as the other boards (`harness/linux/vectors/`) |
| Timing | `time_us_64()` (1 MHz system timer) through `harness/common/common.c`, printed with `%.6f` |
